# ClearEnergy

ClearEnergy is a simple student website about saving energy, renewable energy and electricity costs. The project supports SDG 7: Affordable and Clean Energy.

## How to open it

Open `index.html` in a web browser.

You can also open the folder in VS Code, right-click `index.html` and choose **Open with Live Server**.

No installation or Node.js is required.

## How to use it

Use the menu at the top to move between five screens:

- **Home** — a short introduction.
- **Energy Tips** — simple ways to use less energy.
- **Renewable Energy** — information about solar, wind and hydropower.
- **Calculator** — choose a device, adjust the sliders and see its estimated cost.
- **About** — information about the project, SDG 7 and the team.

The calculator updates automatically when a value changes.

## Project files

- `index.html` — page content.
- `css/style.css` — colours and layout.
- `js/script.js` — navigation and calculator.
- `assets/` — logo, images and icons.
